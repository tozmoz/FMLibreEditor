FMLibreEditor - real-time editor for Football Manager 27 (Windows, Game Pass or Steam)

1. Extract this folder anywhere you like (Documents, for example).
2. Start Football Manager 27 and load a save (the main menu is not enough).
3. Double-click FMLibreEditor.exe, then click "Connect".
4. If Windows says "Windows protected your PC": "More info", then "Run anyway". The
   program is not signed yet, which is why the warning appears.
5. Save your game under a new name before you edit. The game shows a change once you
   press Continue.

Full guide: https://github.com/tozmoz/FMLibreEditor/blob/main/docs/INSTALL.md
