FMLibreEditor - real-time editor for Football Manager 27 (Windows, Game Pass or Steam)

TÜRKÇE
1. Bu klasörü istediğiniz bir yere çıkarın (örneğin Belgeler).
2. Football Manager 27'yi açın ve bir kayıt yükleyin (ana menü yetmez).
3. FMLibreEditor.exe'ye çift tıklayın, sonra "Bağlan" düğmesine basın.
4. Windows "Windows kişisel bilgisayarınızı korudu" derse: "Ek bilgi", sonra "Yine de
   çalıştır". Program henüz imzalı olmadığı için bu uyarı çıkar.
5. Düzenlemeden önce kaydınızın bir yedeğini alın. Oyun, değişiklikleri bir kez Devam'a
   bastıktan sonra gösterir.
Ayrıntılı rehber: https://github.com/tozmoz/FMLibreEditor/blob/main/docs/KURULUM.md

ENGLISH
1. Extract this folder anywhere you like (Documents, for example).
2. Start Football Manager 27 and load a save (the main menu is not enough).
3. Double-click FMLibreEditor.exe, then press "Connect".
4. If Windows says "Windows protected your PC": "More info", then "Run anyway". The
   program is not signed yet, which is why the warning appears.
5. Back up your save before you edit. The game shows a change once you press Continue.
Full guide: https://github.com/tozmoz/FMLibreEditor/blob/main/docs/INSTALL.md
