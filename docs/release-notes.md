## Download / İndir

- **FMLibreEditor-Setup.exe**: the installer, recommended / kurulum programı, önerilen
- **FMLibreEditor-portable.zip**: no installation / kurulumsuz
- **FMLibreEditor-macOS.zip**: for macOS / macOS için

Windows 10 or 11 with Football Manager 27 from Xbox / Game Pass or Steam; macOS (Apple
silicon or Intel) with FM27 from Steam.

How to install and use it: [English](https://github.com/tozmoz/FMLibreEditor/blob/main/docs/INSTALL.md) · [Türkçe](https://github.com/tozmoz/FMLibreEditor/blob/main/docs/KURULUM.md)

Windows may say "Windows protected your PC" because the program is not signed yet: choose
"More info", then "Run anyway". / Windows "Windows kişisel bilgisayarınızı korudu" diyebilir:
"Ek bilgi", sonra "Yine de çalıştır".

macOS may say it could not verify the app because it is not notarized yet: open System
Settings › Privacy & Security and choose "Open Anyway". / macOS uygulamayı doğrulayamadığını
söyleyebilir: Sistem Ayarları › Gizlilik ve Güvenlik'te "Yine de Aç"ı seçin.
